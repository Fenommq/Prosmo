# 🍿 «Что посмотреть»

Сайт-кинотека: список фильмов, сериалов, аниме и мультфильмов, которые хочется посмотреть.
Создавайте доски, добавляйте тайтлы с постером и описанием, отмечайте просмотренное галочкой.

## Как открыть

1. Откройте папку `Для просмотра`.
2. Дважды щёлкните `index.html` (или `Запустить сайт.bat`).

Ничего устанавливать не нужно — это обычный сайт на HTML, CSS и JavaScript.
Работает офлайн; данные хранятся в браузере (IndexedDB, резервный вариант — localStorage).

> Для лучшего результата открывайте в Chrome, Edge или Firefox.

## Что умеет

- **Регистрация и вход.** Несколько аккаунтов в одном браузере. Пароли хранятся в виде
  хеша PBKDF2-SHA256 с солью, а не открытым текстом.
- **Доски.** Создание, редактирование, удаление. У каждой доски есть название,
  описание и переключатель «Публичная / Закрытая».
- **Тайтлы.** Название, тип (фильм, сериал, аниме, мультфильм, документальный, другое),
  год, описание и постер: загрузка файла (сжатие до 900 px), drag & drop или ссылка на картинку.
- **Галочка «просмотрено».** Отмечайте просмотренное прямо на карточке; считается
  прогресс и процент по доске. Фильтры «Все / Не просмотрено / Просмотрено»,
  поиск по названию и описанию, сортировка.
- **Публичные доски.** Доски с включённой публичностью видны в разделе «Обзор»
  всем пользователям этого браузера. Закрытые видит только владелец.
- **Поделиться и перенести.** Кнопка-ссылка копирует адрес доски, а кнопка со стрелкой
  скачивает доску в `.json`. На главной есть «Импорт» — так доску можно перенести
  в другой браузер или на другой компьютер (вместе с постерами).

## Структура

```
Для просмотра/
├── index.html          разметка страницы
├── styles.css          оформление (тёмная тема, адаптивность)
├── store.js            хранение данных, аккаунты, доски, тайтлы
├── app.js              интерфейс, маршруты, модальные окна
├── Запустить сайт.bat  открывает сайт в браузере по умолчанию
└── README.md
```

## Важно про данные

Сайт статический, без сервера, поэтому:

- аккаунты, доски и постеры живут **только в текущем браузере** (на этом устройстве);
- очистка данных сайта в браузере удалит всё — при необходимости сделайте экспорт досок;
- ссылка на доску открывается на этом же устройстве, для переноса на другое
  используйте экспорт/импорт JSON;
- ограничение объёма зависит от браузера (обычно сотни мегабайт в IndexedDB).

## Сброс данных

Быстрый способ — выполнить в консоли браузера (F12) на открытой странице сайта:

```js
await Store.resetAll();
location.reload();
```

Полная очистка хранилища: настройки сайта в браузере (значок слева от адреса) →
«Сайты» → удалить данные для этой страницы. Либо в консоли:

```js
indexedDB.deleteDatabase('watchlist-studio');
localStorage.clear();
location.reload();
```
